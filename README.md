# SyncFlow API

**SyncFlow** — высокопроизводительный REST API бэкенд, разработанный на Go. Сервис предназначен для управления бизнес-сущностями (пользователи, задачи) и агрегации статистики в реальном времени.

Проект спроектирован с упором на чистую архитектуру, высокую тестируемость, безопасность и легкость горизонтального масштабирования.

## 🛠 Технологический стек

*   **Язык:** Go (стандартная библиотека `net/http` с кастомной оберткой для роутинга)
*   **База данных:** PostgreSQL
*   **Драйвер БД:** `pgx` (с использованием пула соединений)
*   **Миграции:** `golang-migrate`
*   **Документация:** Swagger
*   **Инфраструктура:** Docker, Docker Compose, Makefile
*   **Логирование:** Структурированное логирование (`slog` / `zap`)

## 🏗 Ключевые архитектурные решения

1.  **Feature-Sliced Design:** Проект разделен по вертикальным бизнес-срезам. Каждая фича (управление пользователями, задачами, аналитика) изолирована и содержит собственные слои: транспорт (HTTP), бизнес-логику (Service) и доступ к данным (Repository). Это минимизирует связанность кода (coupling) и упрощает поддержку.
2.  **Изоляция домена:** Ядро приложения (доменные модели и интерфейсы) полностью независимо от инфраструктуры. Оно ничего не знает о базах данных или HTTP, что позволяет легко покрывать бизнес-логику unit-тестами.
3.  **Custom HTTP Layer:** Написан легкий слой абстракции над стандартным `net/http`. Включает в себя продвинутый роутинг, цепочки middleware, удобную обработку path/query параметров, декодирование JSON и унифицированный формат отправки ошибок.
4.  **Graceful Shutdown:** Корректное завершение работы сервера с ожиданием закрытия активных соединений и освобождением ресурсов пула БД.
